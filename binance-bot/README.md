# Binance Market Bot — Telegram-бот для анализа рынка Binance

Бот показывает цены и статистику пар Binance, топ движений за сутки, делает
технический анализ по свечам (SMA/EMA, RSI, MACD, полосы Боллинджера, уровни
поддержки и сопротивления), рисует графики и присылает ценовые уведомления.

- Только **публичные** эндпоинты Binance (`ticker/24hr`, `ticker/price`, `klines`, `depth`).
- **Никаких API-ключей Binance, ордеров и торговли.**
- Индикаторы считаются самостоятельно на pandas/numpy и покрыты тестами.

> ⚠️ Аналитика бота не является финансовым советом.

## Требования

- Python 3.11+
- Токен Telegram-бота

## Получение токена у @BotFather

1. Откройте в Telegram [@BotFather](https://t.me/BotFather) и отправьте `/newbot`.
2. Введите отображаемое имя бота, затем username (должен заканчиваться на `bot`, например `my_binance_market_bot`).
3. BotFather пришлёт токен вида `123456789:AAH...`. Храните его в секрете — с ним кто угодно сможет управлять ботом.
4. Если токен утёк, отзовите его в @BotFather: `/revoke`.

## Установка

```bash
cd binance-bot
python -m venv .venv
# Linux/macOS:
source .venv/bin/activate
# Windows (PowerShell):
.venv\Scripts\Activate.ps1

pip install -r requirements.txt
```

## Настройка

Скопируйте `.env.example` в `.env` и вставьте токен:

```bash
cp .env.example .env
```

```dotenv
TELEGRAM_BOT_TOKEN=123456789:ваш-токен
```

Файл `.env` в `.gitignore` и в репозиторий не попадает. Вместо `.env` можно
задать переменную окружения `TELEGRAM_BOT_TOKEN` напрямую.

Необязательные переменные:

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `BINANCE_BASE_URL` | `https://api.binance.com` | Адрес API. Если Binance отвечает HTTP 451 (регион заблокирован), используйте `https://data-api.binance.vision` — это официальный зеркальный хост только с рыночными данными |
| `ALERTS_DB_PATH` | `data/alerts.db` | Файл SQLite с уведомлениями |
| `ALERT_CHECK_INTERVAL` | `60` | Как часто (в секундах) проверять уведомления |
| `TOP_MIN_QUOTE_VOLUME` | `10000000` | Минимальный оборот пары за 24ч в USDT для `/top` |
| `LOG_LEVEL` | `INFO` | Уровень логирования |

## Запуск

```bash
python -m bot
```

Бот работает через long polling — внешний адрес или вебхук не нужны. Остановка — `Ctrl+C`.

### Docker

```bash

```

## Команды

| Команда | Что делает |
|---|---|
| `/start`, `/help` | Приветствие и справка |
| `/price <SYMBOL>` | Цена, изменение за 24ч, максимум/минимум, объём, bid/ask |
| `/top [N]` | Топ-N растущих и падающих USDT-пар за 24ч (по умолчанию 10, максимум 20) среди пар с оборотом выше порога |
| `/analyze <SYMBOL> [interval]` | Технический анализ: SMA20/50/200, EMA12/26, RSI(14), MACD(12,26,9), Боллинджер(20, 2σ), уровни, баланс стакана и итоговая оценка тренда |
| `/chart <SYMBOL> [interval]` | PNG-график: свечи, SMA20/50, полосы Боллинджера, уровни, RSI и MACD |
| `/alert <SYMBOL> <above\|below> <price>` | Уведомить, когда цена станет выше/ниже заданной |
| `/alerts` | Список ваших уведомлений |
| `/unalert <id\|all>` | Удалить уведомление (или все) |

**Символ** можно писать как угодно: `BTC`, `btcusdt`, `ETH/BTC`. Если котируемая
валюта не указана, подставляется USDT (`SOL` → `SOLUSDT`). Для пар с короткой
базой и котировкой BTC/ETH/BNB пишите через слэш: `OP/BTC`.

**Интервалы**: `1m 3m 5m 15m 30m 1h 2h 4h 6h 8h 12h 1d 3d 1w 1M`, по умолчанию `4h`.
Анализ строится по последним 300 свечам.

### Примеры

```
/price BTC
/top 5
/analyze ETH 1d
/chart SOLUSDT 1h
/alert BTC above 75000
/alert ETH below 2500
/alerts
/unalert 3
```

Пример ответа `/analyze`:

```
📊 BTCUSDT · 4h · 300 свечей
Цена: 67 123.45 (за период +8.12%)

Скользящие средние
SMA20: 66 410.20 (цена выше ↑)
SMA50: 65 102.77 (цена выше ↑)
SMA200: 62 980.05 (цена выше ↑)
...
Итог: 🟢 Бычий (счёт +3.5)

⚠️ Не является финансовым советом. ...
```

### Как считается итог тренда

Каждый признак добавляет или вычитает баллы:

- цена выше/ниже SMA20 — ±1;
- SMA20 выше/ниже SMA50 — ±1;
- цена выше/ниже SMA200 (если хватает истории) — ±1;
- MACD выше/ниже сигнальной линии — ±1;
- RSI: 50–70 → +0.5, 30–50 → −0.5, перекупленность ≥70 → −0.5, перепроданность ≤30 → +0.5.

Сумма ≥ 1.5 — «бычий», ≤ −1.5 — «медвежий», иначе — «нейтральный».
Выход цены за полосы Боллинджера отмечается отдельным предупреждением.

### Уведомления

- Проверяются фоновой задачей (JobQueue) раз в `ALERT_CHECK_INTERVAL` секунд одним запросом всех цен.
- Одноразовые: после срабатывания удаляются.
- До 20 уведомлений на чат; хранятся в SQLite и переживают перезапуск.

## Обработка ошибок

- Неизвестная пара → «Торговая пара … не найдена на Binance».
- Сеть/5xx → до 3 повторов с экспоненциальной паузой, затем «Binance сейчас недоступен».
- Лимит запросов (HTTP 429) → повтор с учётом `Retry-After`; бан IP (HTTP 418) не повторяется.
- HTTP 451 (регион) → подсказка про `BINANCE_BASE_URL`.

## Тесты

```bash
pip install -r requirements-dev.txt
pytest
```

HTTP-запросы к Binance в тестах подменяются через `httpx.MockTransport` — сеть не нужна.

├── tests/
├── requirements.txt
├── requirements-dev.txt
├── .env.example
└── Dockerfile
