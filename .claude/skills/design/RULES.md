# Дизайн «Системы» — правила и каталог

Источник истины — `theme.css` (токены, компоненты) и `fx.js` (движение). Этот файл — выжимка: что из них брать и как. Образ: ночной кадр sci-fi фильма, где жизнь — интерфейс персонажа. Монохром, крупная типографика Tektur, свет вместо рамок.

## Принципы

1. **Монохром — основа, цвет — сигнал.** Цвет сферы только в тексте-подписи сферы, тонкой полосе прогресса, точке-маркере и свечении.
2. **Одно «вау» на экран** (гигантское число или слово). Всё остальное тихое.
3. **Свет вместо рамок:** глубина из свечения, зерна и виньетки; тени и стекло не используются.
4. **Движение отвечает на действие** пользователя или событие, а не на скролл.
5. **Новое собирается из существующих компонентов.** Новый класс — только когда ни один из каталога не подходит; тогда он пишется в `theme.css` теми же токенами и добавляется в каталог ниже.

## Цвет

| Токен | Значение | Где |
|---|---|---|
| `--void` | #000 | фон |
| `--ink-1` | #0E0E0F | карточки |
| `--ink-2` | #1A1A1C | неактивные кнопки, поля |
| `--line` / `--line-2` | белый 8% / 18% | разделители / обводки, HUD-уголки |
| `--fog` | #8A8A90 | вторичный текст |
| `--dim` | #6A6A72 | неактивные иконки |
| `--bone` | #F2F2EF | основной текст, **активное состояние** |
| `--money` `--dfir` `--body` | #E9C46A #6FE3F2 #FF5A5F | сигналы сфер |

- **Активное** (вкладка, сегмент, чип, выбранный период) = заливка `--bone` + чёрный текст, либо текст `--bone` + линия 1px `--bone` снизу. Цветное активное состояние не бывает.
- Цвет сферы допустим: имя сферы в плитке (`.t-name`), полоса прогресса сферы, точка в легенде («● Деньги +0»), сумма дохода (`--money`), опасное действие — контур `--body`.
- Цвет сферы недопустим: заливки и рамки кнопок, вкладок, сегментов, полей, карточек; цветные полоски слева у строк; цветные точки-статусы у задач.
- Опасное действие: `.save-btn.sheet-ok-danger` (прозрачная, контур и текст `--body`).

## Типографика

- **Tektur** (`.disp`, `--font-display`): заголовок экрана (`.header h1`: «Квесты», «Тело», «Обзор»), гигантские числа (уровень, `.wk-num`, суммы итогов), буква тренировки.
- **Golos Text** — всё остальное: 15 px основной, 13–14 px вторичный, 11–12 px подписи.
- Подписи капсом с разрядкой — только мелкие ярлыки над/под числом: `.wk-lbl`, «УРОВЕНЬ», «НАГРУЗКА ЗА 7 ДНЕЙ», заголовок «КВЕСТ ДНЯ». Обычные заголовки карточек — `.card-title`, строчные, `--fog`.
- Числа — `tabular-nums`; валюта ₸ через пробел.

## Движение

Токены: `--t-fast` 140 мс, `--t-base` 260, `--t-slow` 520, `--t-epic` 1100; `--ease-out` для появления и переездов. Анимируются только `transform` и `opacity`.

| Когда | Функция |
|---|---|
| Число изменилось (XP, суммы, счётчики) | `fxTicker(el, to, fmt)` |
| Квест/привычка выполнены | `fxQuestDone(el, xp)` |
| Ввод сохранён, последний подход | `fxFlash(el)` |
| Чип улетает во вкладку | `fxFly(from, to)` |
| Линия рисуется при открытии вкладки | `fxDraw(path)` |
| Новый уровень | `fxLevelUp(info, lv)` — единственная длинная анимация |
| Достижение | `fxAchievement(a)` |
| Бегущая сводка | `fxMarquee(el, html)` |
| Подсветка под пальцем, наклон | классы `.spot`, `.tilt` (слушатели уже в fx.js) |

Правила: одновременно не больше двух эффектов; бесконечные — только transform/opacity и на паузе при скрытой вкладке; при `prefers-reduced-motion` состояние меняется мгновенно (`fxRM`). Появление карточек при скролле и hover-эффекты на всём подряд не используются.

## Чек-лист сверки (каждый пункт — да/нет)

1. Цвет сферы встречается только в местах из раздела «Цвет»; активные состояния — bone.
2. Каждый элемент взят из каталога; новые классы (если есть) добавлены в theme.css и каталог.
3. Tektur — только заголовок экрана и крупные числа; капс — только мелкие ярлыки.
4. Отступы и радиусы совпадают с соседями на эталоне (карточки во всю ширину контейнера, промежуток ~12–16 px).
5. На экране одно «вау»; рядом с эталоном экран не выглядит чужим.
6. Ширина 375 px: ничего не переносится уродливо, цели касания ≥ 44 px, текст не мельче 11 px.
7. Анимации — из таблицы «Движение», есть поведение для reduced motion.
8. Тексты по-русски, без эмодзи и стрелок «→» в кнопках.
