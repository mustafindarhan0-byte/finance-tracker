# /review — проверка перед пушем

Вход: файл спеки и пункты, которые делал `/build`; база — последний запушенный коммит (`origin/master`).

1. **Тесты.** `node tools/test.cjs` — все `ok`.
2. **Диф.** `git diff origin/master --stat`, затем по файлам. Ищи: текст пользователя в `innerHTML` без `escapeHtml`; `toISOString()` от локальной даты; запись в Firestore мимо `colPut/batch*` (нет `updatedAt`, удаление без tombstone); новая коллекция без правки `firestore.rules`; версии ассетов не подняты; личные данные или реальные выписки в фикстурах; `TECH_OVERVIEW.md`/`assets_src/` в индексе git.
3. **Браузер.** `preview_start` с `name:"finance-tracker"`, новое тестовое пространство (`createNewSpace`). Пройди каждый браузерный критерий приёмки; консоль без ошибок; ширина 375 px и тёмная тема. Затем удали тестовое пространство (процедура в CLAUDE.md).
4. **Вердикт.** Таблица: критерий → выполнен / нет → доказательство (имя теста или что увидел в браузере, скриншот для визуального).

Если хоть один критерий не выполнен или пункт 2 что-то нашёл — перечисли и вернись в `/build` с этими пунктами, затем снова `/review`.

Готово, когда у каждого критерия есть вердикт «выполнен» с доказательством. Тогда — коротко пользователю по-русски, что сделано, и вопрос «запушить?».
