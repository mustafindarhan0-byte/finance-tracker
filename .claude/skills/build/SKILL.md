# /build — спека → код

Вход: файл спеки и пункты (по умолчанию — все невыполненные по порядку). Правила кода, тестов и git — в `CLAUDE.md`.

Для каждого пункта:

1. **Найди место.** `node tools/codemap.cjs who/find/section`, затем Read нужного диапазона строк.
2. **Тест первым**, когда пункт содержит логику: добавь проверки из критериев приёмки в подходящий `tests/*.cjs` (или новый по образцу соседних) и убедись, что он красный.
3. **Реализуй** минимально под критерии пункта; соседний код не переделывай.
4. **Зелёный.** `node tools/test.cjs` — все файлы `ok`.
5. **Коммит** локально: одно сообщение на пункт, «что сделано + зачем» (`X3: …`). Хук сам обновит CODEMAP.md.

Независимые пункты можно отдать параллельно агентам (`Agent` с `isolation:"worktree"`, в промпте — путь к спеке, номер пункта и ссылка на CLAUDE.md); после — слей их ветки, прогони тесты, удали worktree (`git worktree remove --force …`, `git branch -d …`).

В конце: если менялись index.html/theme.css/fx.js — подними версии ассетов (см. CLAUDE.md) отдельным коммитом. Если правились `firestore.rules` — скажи пользователю, что их надо опубликовать.

Готово, когда каждый пункт из входа закоммичен, `node tools/test.cjs` зелёный, ничего не запушено. Следующий шаг — `/review`.
