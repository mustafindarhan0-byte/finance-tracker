# Система (finance-tracker)

PWA без сборки: весь код приложения — один `<script>` в `index.html` (~6k строк), плюс `theme.css`, `fx.js` (эффекты), `sw.js`, `manifest.json`. Данные — Firestore (`spaces/{sha256(код)}/…`), правила в `firestore.rules`. Деплой — GitHub Pages из `master`. Общение с пользователем — по-русски, коротко.

## Навигация по коду

Начинай с `CODEMAP.md`: разделы и функции с номерами строк index.html. Дальше:

- `node tools/codemap.cjs who <функция>` — где лежит, что вызывает, кто её вызывает;
- `node tools/codemap.cjs find <часть имени>` / `section <часть заголовка>`;
- читай index.html кусками по номерам строк (Read с offset/limit).

Карта пересобирается git-хуком при каждом коммите с index.html; вручную — `node tools/codemap.cjs`.

## Тесты

`node tools/test.cjs` — все файлы, одна строка на файл. Тесты вырезают куски index.html между заголовками `// ── Раздел ──` и гоняют их в `vm` с заглушками, поэтому переименование заголовка раздела ломает тест — правь оба. Новая логика = чистая функция + тест в `tests/*.cjs` по тому же образцу.

## Правила кода

- Ванильный JS, без зависимостей и сборки. Любой текст пользователя в `innerHTML` — через `escapeHtml`.
- Даты локальные: `today()`, `localDate()`, `parseLocalDate()`; `toISOString()` от локальной даты даёт вчерашний день.
- Запись в базу — через `colPut/colDel` или `batch*` + `commitBatch`: каждая запись получает `updatedAt`, удаление — tombstone (`{deleted:true}`), иначе дельта-синк на других устройствах не увидит изменение. Новая коллекция — ещё и в whitelist `firestore.rules` (правила публикует пользователь в консоли).
- index.html в рабочей копии с CRLF: скрипты-патчи сначала делают `.replace(/\r\n/g,'\n')`.
- Каждый деплой, меняющий `theme.css`/`fx.js`/`index.html`: подними `?v=N` в index.html (2 места) и в `ASSETS` sw.js, и `CACHE_NAME` — все на одно число.

## Данные и приватность

- Репозиторий публичный: в git только обезличенные фикстуры. Реальные выписки, код доступа, личные цифры — никогда. Код доступа не печатай даже в чат.
- Проверки в браузере — только в новом тестовом пространстве (`createNewSpace`), реальное пространство пользователя не трогай. После проверки удали его: `window.confirm=()=>true; await clearAll();`, удали `members/{uid}` и `_meta`, `localStorage.clear()`.
- Локальные, вне git: `TECH_OVERVIEW.md`, `assets_src/` (спеки `SPEC_*.md`), `HANDOFF.md`.

## Git

Коммить локально свободно, по коммиту на завершённый пункт. Пушь только по слову пользователя («запушить»/«да» на вопрос о пуше), в обе ветки: `git push origin game-layer-monochrome-d0-d2:master` и `git push origin game-layer-monochrome-d0-d2`.

## Цикл работы

Новая фича идёт петлёй навыков: `/spec` (интервью → `assets_src/SPEC_*.md` с критериями приёмки) → `/build` (реализация по пунктам) → `/review` (проверка по критериям; не прошло — обратно в `/build`).
